# 吉祥物形象：改自带的、给新 AI 画一个

竞技场里每个 AI 都是一个 24×20 的像素小人，有四个姿势：

| 姿势 | 什么时候用 |
|---|---|
| `idle` | 待机（必填） |
| `idle2` | 待机第二帧，和 `idle` 交替做呼吸 / 摇摆动画 |
| `atk` | 出手攻击 |
| `hurt` | 被打中、出局 |

`idle2`、`atk`、`hurt` 不写时沿用 `idle`。

## 文件放在哪

`数据目录/mascots/<编号>.json`。数据目录在 Windows 上是 `%APPDATA%\Crux Arena`，macOS 上是 `~/Library/Application Support/Crux Arena`，也可以用环境变量 `CRUX_HOME` 指定。

- **编号和自带角色相同**（如 `claude`）就覆盖自带形象；没写的名字、颜色等沿用自带的。
- **编号是新的**就是新角色；配合 `channels.json` 里的同名选手（见 [channels.md](channels.md)）就能上场。
- 新加了选手但还没画形象：竞技场会先用一只同色的小史莱姆顶上。

改完后在托盘菜单点"重新加载自定义形象与通道"，或者重启桌面版。

## 格式

```json
{
  "id": "llama",
  "name": "LLAMA",
  "zh": "小羊驼",
  "maker": "我自己",
  "color": "#f2a65a",
  "idea": "一句话设计说明",
  "palette": { ".": null, "a": "#F2A65A", "b": "#A9743F", "e": "#1B1220" },
  "poses": {
    "idle": [
      "........................",
      "...（共 20 行，每行 24 个字符）...",
      "........................"
    ],
    "idle2": ["…"], "atk": ["…"], "hurt": ["…"]
  }
}
```

- `palette`：一个字符对应一种颜色，`#RRGGBB` 或带透明度的 `#RRGGBBAA`。`"."` 固定表示透明。
- `poses`：每个姿势正好 20 行、每行正好 24 个字符，只能用 `palette` 里有的字符。
- `color`：名字、弹道、论点卡边框用的主题色。
- `id`：小写字母、数字、短横线，最长 32 个字符，和选手编号一致。

## 命令

```bash
crux mascot list                      # 自带的、你画的，以及哪些被覆盖了
crux mascot export claude             # 把自带的小螃蟹导出成像素表，改完就覆盖自带形象
crux mascot new llama --name LLAMA --color "#f2a65a"   # 新角色：从一只小团子模板开始
crux mascot check                     # 校验全部（行数、列数、字符、颜色）
crux mascot preview llama             # 渲染预览 PNG：四个姿势横排
crux mascot reset claude              # 停用你的版本（改名为 .bak），恢复自带形象
```

## 画得好看的几条经验

- **轮廓先行**：用 2–3 个深浅相近的颜色画身体（亮面、主色、暗面），外加一个深色画眼睛。颜色越少越像像素画。
- **全部朝右画**：右边的选手会自动镜像。
- **四个姿势只改局部**：`idle2` 上下动一格或换个小零件；`atk` 眯眼、张嘴、亮出武器；`hurt` 把眼睛画成 `> <` 或 `x x`。
- **底部留一行空**：脚下有阴影。
- **一眼认出是谁**：抓住这个 AI 最有名的一个元素（名字的谐音、logo 的形状、代表色），不要照搬官方 logo。
